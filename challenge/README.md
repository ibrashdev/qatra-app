### متطلبات تسليم المشروع

**المنتج المطلوب**

حل متكامل يعمل بالكامل وجاهز للتشغيل والاستخدام الفعلي. لا يقتصر التسليم على فكرة أو نموذج أولي.

**جهّز مواد التسليم**

1. **رابط تجربة مباشر** — Live Demo — يتيح للجنة تجربة الحل والتحقق من وظائفه.
2. **مستودع GitHub عام** — Public — الشفرة وملفات التشغيل المسموح بنشرها، مع وثائق الإعداد والتشغيل والاعتمادات والتراخيص.
3. **فيديو توضيحي** — يوضح المشروع، بمدة لا تتجاوز دقيقتين.
4. **عرض تقديمي** — PDF أو PowerPoint — يشمل المشكلة والحل وآلية العمل والقيمة المضافة والتقنيات والنتائج وخطة الاستمرار وصور المشروع.
5. **توثيق المحتوى والمصادر** — المصادر الشرعية والمعرفية وكيفية استخدامها والتحقق منها، وسجل الأدوات والتراخيص.

يجوز العرض بالعربية أو الإنجليزية، بالقالب الموحد أو قالب خاص يلتزم بهوية التحدي.

التسليم عبر الموقع الرسمي.
