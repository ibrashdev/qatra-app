# قطرة غيث — مجلد العمل المعتمد

٤ أكتوبر ٢٠٢٦، Asia/Dubai. هذا جذر العمل الجديد المعتمد في D61؛ يحتوي الوثائق الحالية ومراجع التحدي والتصميم الضرورية. مسارا التطبيق المخططان هما `frontend/` و`backend/`؛ لا تعني هذه الحزمة إنشاء التطبيق أو جاهزية الخدمات.

ابدأ من [فهرس الوثائق](docs/README.md)، ثم [سجل القرارات](docs/Decision-register.md) و[متابعة الجاهزية](docs/Readiness.tracker.md). لمهمة برمجية، اقرأ أولًا [دليل البرمجة](docs/Programming-guide.md). [تعليمات الوكلاء](AGENTS.md) تحكم التفويض والاعتمادات.

الهدف المعتمد: نسخة أساسية يوم ٥ أكتوبر ٢٠٢٦، ويوم ٦ للتحقق. D64 يعتمد تغطية المقطع كاملًا عبر الأجزاء المستهدفة بالأسئلة ومراجعات ١/٣/٧ بعد الشرط الأولي؛ الاختيار كلمة أو جزء، والترتيب لأجزاء أكبر، والألعاب ذات الكلمة الواحدة لمواضع مفتاحية واستكمال. تدوير المواضع ومراجعة الأخطاء يقللان التكرار؛ لا سؤال منفصل لكل كلمة. التغطية ليست نسبة نجاح الإجابات أو شهادة حفظ حرفي كامل. D66 (٤ أكتوبر ٢٠٢٦) يحسم الحساب بتعديل صريح لـ D64: هدف الحفظ مقطع، وتغطية أجزائه بإجابات صحيحة دون مساعدة، وسلم مراجعات بفواصل ١ و٢ و٤ أيام وحجم جولة بحسب عدد الأجزاء، ثم تأكيد وصيانة، ونسبة إنجاز عامة = كلمات المؤكد ÷ كلمات نطاق الخطة النشطة للمسارات المختارة. الذكاء الاصطناعي مجاني فقط؛ محرك القواعد بديل دائم.

صرّح المالك في ٤ أكتوبر ٢٠٢٦ بنشر خط الأساس الآمن من وثائق المشروع وتعليمات الأدوار والصور التصميمية الإحدى عشرة إلى [ibrashdev/qatra-app](https://github.com/ibrashdev/qatra-app). تعرض [ملاحظة مراجع التحدي](challenge/README.md) اسمي الملفين المحتفظ بهما محليًا والمستبعدين من المستودع العام حتى موافقة المالك المحددة على نشرهما. لا يثبت هذا التصريح حقوق إعادة نشر أي مرجع ولا يجيز إضافة ترخيص أو إنشاء التطبيق أو تجاوز اعتمادات مراحل التحليل والبنية وتصميم الواجهات والتنفيذ.

D65 يؤكد Next.js/Vercel وFastAPI/Render وSupabase/PostgreSQL/Auth/Storage/pgvector. إعداد المحتوى Background Workflow قابل للاستئناف، وTeaching Agent لبناء خطة المتعلم وتعديلها من المحتوى المنشور والتقدم. ينظم [AGENTS.md](AGENTS.md) العمل: دراسة الطلب أولًا، ثم Sol 6.1 أو Opus 5.5 للتخطيط والقرارات بجهد مناسب، وLuna أو Sonnet 5.5 للمهام الصغيرة والكتابة البرمجية. تبقى قيود D17 والمجاني D60 واعتمادات مراحل التطبيق نافذة.

قرارات ٤ أكتوبر ٢٠٢٦: D68 يجعل Islamic Content MCP مصدر نص الكتابين (جزء عم من QuranEnc، والأربعون النووية من سجلات HadeethEnc بلفظ الأربعين) ويقبل المالك خطر اقتصار قبول التحدي على المصادر المدرجة في مرجعيته العلمية، ويبقى الاكتساب والتحقق الحرفي وتسجيل شروط الناشر لازمين قبل العرض العام. D67 يحدد الأجهزة والمتصفحات وWCAG 2.2 AA، ويتوقع الاستخدام أثناء التحدي بعشرة مستخدمين كحد أقصى. D69 يعتمد D66–D68 وحزمة الوثائق مع [عقد التنفيذ](docs/Implementation-contract.md) كما عدلته هذه القرارات؛ فقرارات التحليل والبنية معتمدة، والتنفيذ (الكود والهيكلة والترحيلات والاعتماديات والنشر) غير مصرح به بعد.

المهمة التالية: المخرجات المتبقية للتحليل والبنية — المتطلبات مجمعة بالوحدة، والمتطلبات غير الوظيفية القابلة للقياس، ومصفوفة الأدوار والصلاحيات، وERD كامل بالمفاتيح، والمخطط الكامل، وصلاحيات كل نقطة نهاية، وتعقيد وتقدير المراحل — وتعرض للاعتماد الصريح قبل أي تنفيذ. ومعها خطر مفتوح غير محسوم (انظر §11 في [عقد التنفيذ](docs/Implementation-contract.md)): مفاتيح الإجابة المحفوظة لدى العميل وإبلاغ العميل عن استخدام التلميح يتيحان لعميل معدّل تضخيم تقدمه (تطبيق دراسة ذاتية بلا شهادات).
