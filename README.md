# قطرة غيث — مجلد العمل المعتمد

٤ أكتوبر ٢٠٢٦، Asia/Dubai. هذا جذر العمل الجديد المعتمد في D61؛ يحتوي الوثائق الحالية ومراجع التحدي والتصميم الضرورية. مسارا التطبيق المخططان هما `frontend/` و`backend/`؛ لا تعني هذه الحزمة إنشاء التطبيق أو جاهزية الخدمات.

ابدأ من [فهرس الوثائق](docs/README.md)، ثم [سجل القرارات](docs/Decision-register.md) و[متابعة الجاهزية](docs/Readiness.tracker.md). لمهمة برمجية، اقرأ أولًا [دليل البرمجة](docs/Programming-guide.md). [تعليمات الوكلاء](AGENTS.md) تحكم التفويض والاعتمادات.

الهدف المعتمد: نسخة أساسية يوم ٥ أكتوبر ٢٠٢٦، ويوم ٦ للتحقق. D64 يعتمد تغطية المقطع كاملًا عبر الأجزاء المستهدفة بالأسئلة ومراجعات ١/٣/٧ بعد الشرط الأولي؛ الاختيار كلمة أو جزء، والترتيب لأجزاء أكبر، والألعاب ذات الكلمة الواحدة لمواضع مفتاحية واستكمال. تدوير المواضع ومراجعة الأخطاء يقللان التكرار؛ لا سؤال منفصل لكل كلمة ولا عدد ثابت مفروض. التغطية ليست نسبة نجاح الإجابات أو شهادة حفظ حرفي كامل. تصميم أدلة التغطية وحجم الجولات Needs Review، وتفاصيل تجميع أهداف الحفظ ونسبة الإنجاز وأثر إخفاق لاحق Needs Input. الذكاء الاصطناعي مجاني فقط؛ محرك القواعد بديل دائم.

صرّح المالك في ٤ أكتوبر ٢٠٢٦ بنشر خط الأساس الآمن من وثائق المشروع وتعليمات الأدوار والصور التصميمية الإحدى عشرة إلى [ibrashdev/qatra-app](https://github.com/ibrashdev/qatra-app). تعرض [ملاحظة مراجع التحدي](challenge/README.md) اسمي الملفين المحتفظ بهما محليًا والمستبعدين من المستودع العام حتى موافقة المالك المحددة على نشرهما. لا يثبت هذا التصريح حقوق إعادة نشر أي مرجع ولا يجيز إنشاء التطبيق أو تجاوز اعتمادات مراحل التحليل والبنية وتصميم الواجهات والتنفيذ.

الترخيص (D66): شفرة المشروع ووثائقه الأصلية مرخصة بـ MIT وفق [LICENSE](LICENSE). نصوص المصادر الشرعية وطبعاتها، ومواد التحدي، ومكونات الأطراف الثالثة خارج هذا الترخيص وتبقى لأصحابها بشروطها.

D65 يؤكد Next.js/Vercel وFastAPI/Render وSupabase/PostgreSQL/Auth/Storage/pgvector. إعداد المحتوى Background Workflow قابل للاستئناف، وTeaching Agent لبناء خطة المتعلم وتعديلها من المحتوى المنشور والتقدم. ينظم [AGENTS.md](AGENTS.md) العمل: دراسة الطلب أولًا، ثم Sol 6.1 أو Opus 5.5 للتخطيط والقرارات بجهد مناسب، وLuna أو Sonnet 5.5 للمهام الصغيرة والكتابة البرمجية. تبقى قيود D17 والمجاني D60 واعتمادات مراحل التطبيق نافذة.
