# قطرة غيث — سجل القرارات الجاري

الإصدار ١٢ · ٤ أكتوبر ٢٠٢٦ · Asia/Dubai. هذا سجل القرارات المعتمدة ومراجع أثرها في المشروع. يحفظ المعرفات الثابتة؛ يتقدم القرار الأحدث عند التعارض. الاعتماد هنا للقرار ونطاقه، ولا يثبت تنفيذ التطبيق أو التحقق من الخدمات أو حقوق الطبعات.

مصدر الاعتماد: قرارات المالك الصريحة بتاريخ ٣ أكتوبر ٢٠٢٦ عن الموعد والحفظ والتغييرات اليومية والعمل دون اتصال والمجاني والجذر والمصادر والتصميم. أحدث اعتماد لسياسة الحفظ هو «اعتمد تغطية المقطع كاملا لكن بشرط تخفيف الملل» مع اختيار جزء وترتيب أجزاء كبيرة واختبار الكلمات المفتاحية (D64). طلب المالك بتاريخ ٤ أكتوبر ٢٠٢٦ يحدد محتوى الجذر بوثائق المشروع ومراجعها الضرورية؛ لا يغير اعتماد متطلبات المنتج أو يفتح مرحلة تنفيذ. ويؤكد طلب المالك في اليوم نفسه الحزمة التقنية وفصل سير المحتوى عن وكيل التعليم وقياس الاستخدام وفق D65؛ وتحدد تعليمات AGENTS.md قاعدة النماذج لكل مهمة.
