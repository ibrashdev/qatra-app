# قطرة غيث — سجل القرارات الجاري

الإصدار ١٨ · ٤ أكتوبر ٢٠٢٦ · Asia/Dubai. هذا سجل القرارات المعتمدة ومراجع أثرها في المشروع. يحفظ المعرفات الثابتة؛ يتقدم القرار الأحدث عند التعارض. الاعتماد هنا للقرار ونطاقه، ولا يثبت تنفيذ التطبيق أو التحقق من الخدمات أو حقوق الطبعات.

مصدر الاعتماد: قرارات المالك الصريحة بتاريخ ٣ أكتوبر ٢٠٢٦ عن الموعد والحفظ والتغييرات اليومية والعمل دون اتصال والمجاني والجذر والمصادر والتصميم. اعتماد المالك لسياسة الحفظ في ٣ أكتوبر هو «اعتمد تغطية المقطع كاملا لكن بشرط تخفيف الملل» مع اختيار جزء وترتيب أجزاء كبيرة واختبار الكلمات المفتاحية (D64). طلب المالك بتاريخ ٤ أكتوبر ٢٠٢٦ يحدد محتوى الجذر بوثائق المشروع ومراجعها الضرورية؛ لا يغير اعتماد متطلبات المنتج أو يفتح مرحلة تنفيذ. ويؤكد طلب المالك في اليوم نفسه الحزمة التقنية وفصل سير المحتوى عن وكيل التعليم وقياس الاستخدام وفق D65؛ وتحدد تعليمات AGENTS.md قاعدة النماذج لكل مهمة. وفي ٤ أكتوبر ٢٠٢٦ سجل المالك D66 (حساب الإتقان بتفويض «use best practice» واعتماده تعديلًا لـ D64) وD67 (الأجهزة والمتصفحات وحجم الاستخدام) وD68 (Islamic Content MCP مصدرًا للكتابين) وD69 (اعتماد القرارات والحزمة والعقد وقرارات البناء) وD70 (مدخلات المتطلبات غير الوظيفية: التوافر حتى ٣١ أكتوبر ٢٠٢٦ وإيقاظ الخادم المجاني وغياب النسخ الاحتياطية القابلة للتنزيل وناشر المحتوى الوحيد) وD71 (اعتماد مخرجات التحليل مع ثلاثة تعديلات: كتالوج عام بالبيانات الوصفية للزائر، وحقوق حساب العرض كالمتعلم، والمالك مراجع المحتوى حاليًا) وD72 (مدخلات المعمارية: ترتيب خطة جزء عم، وقبول خطر مفاتيح الإجابة للنسخة الأساسية، والإبقاء دافئًا بمهمة GitHub Actions مجدولة، وتوضيح معنى «10 max»)؛ لا يفتح هذا الاعتماد مرحلة تنفيذ: اعتمد المالك مخرجات التحليل في PRD v14 (D71) وانتهت مرحلة التحليل، وأعدت المخرجات المعمارية مسودات Needs Review (Database-schema.md وAPI-spec.md والخطة المرحلية في Qatra-build-plan.md) بانتظار اعتماد المالك الصريح، والتنفيذ غير مصرح به حتى اعتمادها صراحة.
