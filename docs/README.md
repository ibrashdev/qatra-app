# قطرة غيث — الوثائق الجارية

الإصدار ٢٩ · ٥ أكتوبر ٢٠٢٦ · Asia/Dubai. يدرج هذا الإصدار تسليم تحسينات Figma إلى الشفرة ويحدث سجل Figma إلى v8. يعالج تعارض سجلي الإصدار ٢٨ المتوازيين بتثبيت سجل main كاملًا تحت عنوان «سجل الإصدار ٢٨». تحديث وثائقي فقط؛ لا اعتماد مرحلة ولا تغيير في شيفرة التطبيق.

سجل الإصدار ٢٨ · ٥ أكتوبر ٢٠٢٦ · Asia/Dubai. يحدث هذا الإصدار أرقام إصدارات الفهرس (Programming-guide الإصدار 21، وAPI-spec الإصدار ١٫٥، وImplementation-contract v1.10، وUI-screens الإصدار ١٫٥، وUI-design الإصدار ١٫٣، وDelivery-and-baseline الإصدار ١٧) ويلحق بفقرة الحالة وقائع ما بعد الإصدار ٢٧ (دمج PR #13 وPR #14 وPR #15؛ وS-03 وS-04 ومتابعة F0 وخط أنابيب المحتوى لنطاق D83 وتقارير الاستضافة)؛ والفهرس نفسه سجل تنفيذ لا يمنح اعتمادًا ولا يضيف قرارًا (آخر قرار مسجل D83). أضاف الإصدار ٢٧ فهرسة القرارين D82 وD83 اللذين سجلهما المالك (اعتماد تصميم الصوت والرابط العلني واختيار الجدول الزمني؛ ثم منح G4 وG6 للنطاقين المحددين) في سجل القرارات، وإلحاق وقائع الدمج (W-OPS2 وPR #11) بفقرة الحالة، وتحديث أرقام إصدارات الفهرس؛ والفهرس نفسه سجل تنفيذ لا يمنح اعتمادًا. أضاف الإصدار ٢٦ (٥ أكتوبر ٢٠٢٦) فهرسة D82 وإلحاق وقائع الدمج بعد الإصدار ٢٥ بفقرة الحالة. أضاف الإصدار ٢٥ (٤ أكتوبر ٢٠٢٦؛ سجل تنفيذ، دون اعتماد جديد من المالك) وقائع Sprint 2 إلى فقرة الحالة وحدّث أرقام إصدارات الفهرس. الجذر qatra-app؛ وثائق ومراجع ضرورية فقط. القرارات المعتمدة تتقدم على التصميم المقترح والصور. الحالات: Approved للقرار المحدد، Needs Input للمتطلب غير المحسوم، Needs Review للتصميم المعد، Implemented/Verified لا تستعملان دون العمل ودليله.
